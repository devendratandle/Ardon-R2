# Benchmark snapshot — v0.3.0 (June 2026)

Per-version record of the Ardon-R2 vs R comparison, so we can see how
performance progresses release to release. `benchmarks/README.md` always
holds the *latest*; this folder keeps the history.

## Environment
- CPU: 6-core, AVX2+FMA, no AVX-512.
- R 4.5.3, **default reference BLAS** (single-threaded, no AVX).
- Ardon-R2 v0.3.0, release build (`dgemm` AVX2-multiversioned + Oracle multicore).

## Results

| Operation | R 4.5.3 | Ardon-R2 v0.3.0 | R2 speedup |
|---|---|---|---|
| `%*%` matmul 1024×1024 | 0.72 s (2.98 GFLOP/s) | 0.050 s | **14.4×** |
| `crossprod` 100k×50 | 0.13 s | 0.052 s | **2.5×** |
| `sum` 5e7 | 0.06 s | 0.042 s | **1.4×** |
| `lm` 100k×2 | 0.02 s | 0.013 s | **1.5×** |

Single-core SIMD micro-benchmark (GEMM macro-kernel):
SSE2 10.5 → AVX2 30.6 GFLOP/s (**2.9×/core**); combined AVX2+6-core
**71–77 GFLOP/s** (~7× over SSE2-serial).

## Correctness (deterministic, identical in R and R2)
matmul-sum `729`, crossprod-sum `693`, `lm` coef `(2, 3, −1.5)`.

## Notes / caveats
- Big matmul gap is vs **default R's reference BLAS**; against R+OpenBLAS/
  MKL it narrows. Worth re-running on an optimized-BLAS R.
- `crossprod`/`sum` are memory-bandwidth-bound → modest, expected wins.
- AVX-512 tier present but **unverified** (no AVX-512 on this CPU).

## What changed since the previous record
First recorded snapshot. v0.3.0 introduced multi-core + AVX2/AVX-512
multiversioned linear algebra (prior versions were single-threaded SSE2),
plus out-of-core compute and Parquet import.
